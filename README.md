## 📲 Описание / Description

**getoutfitsapp** — мобильное приложение для управления гардеробом, хранения вещей, создания и подбора аутфитов. Всё, что нужно для стиля — всегда под рукой!

**getoutfitsapp** is a mobile app for managing your wardrobe, storing items, and creating outfit suggestions. All your style essentials in one place!

---

## 🚀 Функциональность / Features

- 🧑‍💼 Онбординг для новых пользователей / Onboarding screens
- 🔐 Регистрация и вход / Authentication (Login/Signup)
- 👚 Управление гардеробом: добавление, просмотр, редактирование вещей / Closet management: add, view, edit items
- 🔎 Детальный просмотр вещей / Item detail view
- 🎲 Поиск и подбор аутфитов / Find and suggest outfits
- 🪞 Экран примерки / Try-on screen
- 💾 Просмотр и сохранение капсул / Saved capsule outfits
- 👤 Профиль пользователя / User profile
- 📱 Кроссплатформенность: Android, iOS / Cross-platform: Android, iOS

## ⚡ Установка / Getting Started

1. Клонируйте репозиторий / Clone the repository:
   ```sh
   git clone https://github.com/25angel/getoutfitsapp.git
   cd getoutfitsapp
   ```
2. Установите зависимости / Install dependencies:
   ```sh
   flutter pub get
   ```
3. Запустите приложение / Run the app:
   ```sh
   flutter run
   ```
